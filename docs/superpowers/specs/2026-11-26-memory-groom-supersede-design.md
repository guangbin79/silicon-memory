# 2026-11-26 做梦（dream）接口设计·修订版 v2

> 取代 `/tmp/opencode/2026-11-26-memory-groom-supersede-design.md`。修订要点：取消 LLM 裁决机制；哲学定为"加深重要、遗忘不重要，正确是反复记忆的结果"；实例指针无人工豁免；经验层强度键定义。

## 意图
三层记忆只增不清：①近重去重覆盖不全（热记忆直写路无带处理、同义改写滑过 0.98；经验层 capture 预检不强制）；②矛盾无自动触发面。实证：2026-11-25 注入面两条近逐字重复全局 preference 双双注入。

## 哲学（用户裁定 2026-11-26，全设计地基）
**做梦＝记忆巩固：将重要的记忆加深，将不重要的记忆遗忘；不从正确与否出发——正确是反复记忆的结果。**

- **加深**＝反复记忆：touch／再确认／再召回刷新 `updated_at`/`last_recalled_at`（写入面与召回面既有机制，dream 只读信号）。
- **遗忘**＝不再被反复记忆：**TTL 收账是主遗忘引擎**；近重对 LWW 取代只是加速器。
- **正确**＝被反复记忆而存活的内容——系统输出，非任何相位输入。因此**取消裁决机制**：无需 LLM 判同题性/正确性。
- **误遗忘自修复**：重要记忆被错杀后会被再次说起、再 touch，排序键刷新→复活重裁翻回；翻不回的本就该忘。**复活重裁＝正确性机制本身**，不是补丁。
- 否定近邻陷阱自动消解：重述与翻供同等待遇，方向永远由时间定，新者必存活。

## 核心机制（全机械，零 LLM）
1. **检测**：同域（project 桶／全局桶）存量向量配对，cos≥`pair_sim`（起步 0.92，配置面，观察窗校准）即候选。
2. **方向（LWW）**：`updated_at` 新者存续（touch＝再确认，最近确认时间非创建时间）；**同刻平局→不执行，进报告留人**（人工仅立法与平局）。
3. **执行**：旧条目挂 `superseded_by=新uid`（可逆指针、零物理删除、不改 status/真值）。**实例指针无人工豁免**：人工 retire＝一次带时间戳的裁定事件，与后续再确认平等进入 LWW；覆盖/翻回人工指针是特性（用户裁定 2026-11-26，对齐"人工仅立法与平局"教条）。
4. **留痕**：dream 日志 JSONL＋maintain 报告全量列对；**人工裁决在报告面事后审**——抽查、错了回滚指针。
5. **复活重裁**：被取代条目再被 touch → 排序键刷新 → 次夜以新侧重配 → 幂等翻回（含翻回人工 retire）。
6. **预算**：`max_per_night`＝200＝**遗忘速率限制**（自然日跨 invocation 记账，report-only 同计费），防单夜剧变。
7. **人立法位置**：pair_sim／max_per_night／fold_sim 阈值与平局仲裁；实例指针全机械。

## dream 接口
`silicon-memory dream [--apply]`（第六根命令，用户命名；rc2 白名单同步）。由 groom 定时调用（02:00 单一拥有者，接线归部署方）；maintain `--scope hot` 降为薄委托，报告契约不变。

| 相位 | 角色 | 语义 |
|---|---|---|
| 1 取代（LWW 近重收敛） | 遗忘加速器 | 配对→定向→apply 才挂指针；无 embedder→`skipped:unavailable` |
| 2 蒸馏冲刷 | 固化 | **带邻居不再提问模型**：≥pair_sim 且 <NEAR_HI(0.98) 的带邻居由应用侧自动新取旧（new=本批新条），`superseded_by IS NULL` 守卫保留；≥NEAR_HI 仍 touch 不新增（既有）；提示词只管蒸馏本身 |
| 3 TTL 收账 | **遗忘主引擎** | 既有 `run_maintenance`，按使用存活；preference/decision 永久、只被取代不过期（刻意保护） |
| 4 噪声清扫 | 机械清理 | 既有 noise_sweep，不变 |

- report-only：相位 1 全管线 dry-run（配对定向照跑、写零落）；相位 2/3 跳过（report_only）；相位 4 dry_run。
- 相位间写提交后才进下一相位（all_vectors 写后读缓存窗口，db.py 注释明令）。
- 部署序：server CLI 先于 mjs 委托面（stale venv 无 dream 子命令→rc2 干净失败）。

## 通知面（notify，邮件就绪）
做梦执行完毕须返回**重要调整内容**，供定时器调用后发邮件通知用户。**分工**：dream 只产出摘要，发邮件归定时器（部署方 cron），本仓零 SMTP 依赖；maintain 委托面报告嵌套同段，调 `dream` 或 `maintain` 都拿得到。

`run_dream` 报告常驻 `notify` 段：`subject`（一行计数）＋`text`（预渲染正文，直接当邮件 body）＋`important[]`（结构化清单）＋`counts`（全量计数）。

**“重要”的筛选全机械**：①平局（H-tie）对全列＋附处置命令（等你定夺）；②翻回对全列（复活重裁方向变化，含翻回人工 retire）；③解释类（preference/decision 等非 fact）取代对全列，附旧/新各一句摘要；④fact 类取代对只计数；⑤预算截断、相位异常（skipped/errors）全列。

**正文一律大白话**：不出现 supersede/LWW/updated_at 等术语——“归并”“让位”“翻回来”“拿不定主意等你定”“久无人用自然过期”；uid 截断展示，仅处置命令里保留完整参数。report-only 也产 `notify`，正文加 `DRY-RUN（未执行）`前缀。正文样例（邮件长这样）：

```
本夜做梦：12 对重复/过时的记忆做了归并，1 条以前压下的记忆重新被提起，
45 条久无人用的事实自然过期，清了 3 条噪声。
⚠ 2 对拿不定主意的等你定（两条同刻被确认，分不出谁新）：
  - 「……」⇄「……」→ 定夺：silicon-memory retire <旧id> --by <新id>
↺ 1 条翻回来了：「……」最近又被反复说起，按时间它最新，已恢复为现行版；
  不同意就反向 retire。
● 偏好/决定有 3 处被新说法取代：「旧表述」→「新表述」……
```


## 分层落点
- **热记忆**：dream 全自动（上表）。
- **全局经验**：groom 矛盾波借 dream 原语（部署方 runner 不动）。**强度键＝`max(created_at, reuses.md 中该 id 最近复用时间)`**——reuses.md＝经验层的反复记忆信号（复用即再确认，append-only 主数据）；groom 波运行时**只读聚合、现算现用**，不回写 frontmatter（090312 判例合规）。复活因此自动：旧经验重新被复用→强度键刷新→下波翻回。经验无 TTL（重要记忆只被取代不过期）。**capture 预检闸**：命中判据＝project+type＋（tags 交集≥1 或 summary/根因行关键词重叠）；命中 id 已在草稿 `related:`/`supersedes:` 链→视为已处置放行；未处置命中须 `--force-new`；闸先于一切写。
- **项目知识库**：dream 不可达（编织论述无条目级时间键、跨仓散布）；修正在写入面——任务收尾 ingest 编译即完成 Supersedes 标记（产生新知与修正旧知同过程）；lint 夜报仅兜漏（抓跳过 ingest 的漂移）。
- **读取面 C**：`/recall` 注入前折叠——同域候选 cos≥`fold_sim`(0.95) 仅保留 `updated_at` 最新，零存储写。

## 裁定链（方案史）
A 认识论分级→B groom 形状→取消裁决（2026-11-26：做梦关键是遗忘错误记忆，非百分百正确；人工裁决在报告面事后审）→哲学定稿（加深/遗忘/正确＝反复记忆）→A1 人工指针豁免提案被驳回（入库已人工裁定；人工仅立法与平局）→经验层强度键（reuses.md 只读聚合）。C 检索面折叠＝止血片。热层进 groom 脚本被否（所有权/引擎/作用域三摩擦）。

## 风险
- 回声噪音复活已退役条目：噪声门过滤＋次夜自收敛＋人事后抽查回滚（无独立抽样相位，报告全量列对即复核面）。
- 误遗忘：自修复机制兜底（复活重裁）；重要类型（preference/decision/经验）无 TTL 不过期。
- 低相似度真矛盾对（cos<0.92 翻供）漏网：新陈述被反复记忆＋旧陈述 TTL 衰减兜底；人工看到可 retire。
- 直写新重述 ≤1 天共存，`/recall` 折叠遮显示面。
- 知识层修正依赖收尾 ingest 纪律，lint 兜漏时滞＝结构代价。
